# *Proyecto HTML - Tarea de Semántica*

***Este proyecto está enfocado en el análisis e identificación de etiquetas semánticas en HTML.***

### ***✅✨ ¿De qué trata?***
*A través de este trabajo se pueden dar una idea clara de lo que implica estructurar un código HTML de forma correcta, limpia y organizada utilizando las etiquetas adecuadas para mejorar la accesibilidad y el SEO.*

### ***✅✨ Contenido del Repositorio***
*1. Evaluación de estructura semántica en sitios web reales.*  
*2. Archivos base de maquetación HTML.*
